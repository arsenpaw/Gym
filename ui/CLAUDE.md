# UI (React SPA)

React single-page app for the fitness club system. It gets all of its data from the API (`api/`) over HTTP and has no direct database access. See the root `CLAUDE.md` for the project overview.

## Screens (from requirements)

- Clients and memberships.
- Visits / check-in.
- Trainers and their schedules.
- Schedule and bookings (group and individual sessions).
- Membership plans.
- Reports.

## Container

The UI has its own `Dockerfile` in `ui/`. `deploy/` uses it.
