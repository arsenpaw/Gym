# Staff Portal UI: Design Spec

Requirements source: [[Fitness Club System]]. The UI covers every row of [[Requirements Coverage]] and talks only to the API.

## Scope

A React single-page app for club staff: receptionists, trainers and admins. It must look modern and be built from libraries, not hand-made widgets.

Out of scope:
- A client self-service portal.
- Translations. The UI text is English.
- End-to-end browser tests.
- Paging. The API has none.

## Stack

| Concern | Choice | Notes |
|---|---|---|
| Build | Vite 8, React 19, TypeScript 6 | From the official `react-ts` template, linted with oxlint |
| UI kit | Mantine 9 (`core`, `dates`, `charts`, `notifications`, `modals`, `hooks`) | Theme: teal primary, rounded, light/dark/auto |
| Calendar | react-big-calendar with `dayjsLocalizer` | Weeks start on Monday |
| Data tables | mantine-datatable 9 | Fills Mantine's gap. `mantine-react-table` was rejected because it only supports Mantine 6 |
| Icons | @tabler/icons-react | Mantine's default icon set |
| Routing | React Router 8 (data router, `lazy` routes) | |
| Server state | TanStack Query 5 | Only through generated hooks |
| HTTP | axios | One instance in `src/api/http.ts` |
| DTOs and client | Orval 8 from the API's OpenAPI document | Generates types, axios calls, TanStack Query hooks, zod schemas and MSW mocks |
| Forms | react-hook-form + `@hookform/resolvers/zod` + `react-hook-form-mantine` | `react-hook-form-mantine` provides Mantine inputs already bound to react-hook-form |
| Validation | zod 4 | Form schemas extend the generated ones |
| Auth | `@auth0/auth0-react` | Auth0 SPA login and access tokens for the API |
| Tests | Vitest 5, Testing Library, MSW 2 | jsdom |

**No custom UI components.** Pages compose library components. When something is missing, find a library first. The only shared pieces are thin compositions of Mantine parts, such as `MembershipBadge` and `StatCard`.

## API changes this UI needs

The OpenAPI document must be good enough to generate code from:

1. **Operation ids.** An `OperationIdTransformer` sets `operationId` to `{Controller}_{Action}`, for example `Clients_List`. Orval then names hooks `useClientsList`.
2. **Strict numbers.** ASP.NET's web defaults read numbers from strings, so every number in the document was typed `integer | string`. `JsonNumberHandling.Strict` is set both for MVC (runtime) and in `ConfigureHttpJsonOptions` (what the OpenAPI generator reads). Requests with quoted numbers now get a 400.
3. **Status codes.** Actions that return `CreatedAtAction` declare `201`, and actions that return `NoContent` declare `204`.
4. **Build-time document.** `Microsoft.Extensions.ApiDescription.Server` writes `ui/openapi/fitnessclub.json` on every Debug build of the API. The file is committed. In build-time mode `BuildTimeDocument` supplies placeholder Auth0 settings, because `Program` runs without real configuration then.

CORS is not needed. In development Vite proxies `/api` to the API, and in Docker nginx does.

## Architecture

```
ui/
  openapi/fitnessclub.json   written by the API build, committed
  orval.config.ts            generates src/api/generated (git-ignored)
  src/
    api/       http.ts (axios + token), problem.ts (error text), generated/
    app/       App, providers, query client, routes, home redirect
    auth/      roles from the token, token bridge, role guard
    layout/    AppShell with role-based navigation
    lib/       dayjs setup, formatting, dates, shared zod pieces
    features/  one folder per screen: page, modals, form schema, tests
    pages/     no-access and not-found pages
    test/      setup, MSW server, auth fake, render helpers, fixtures
```

- **Generated code is never edited.** `npm run generate` runs Orval. It also runs before `dev`, `build`, `test` and `typecheck`.
- **Auth:**
  - `Auth0Provider` uses `cacheLocation="localstorage"` and refresh tokens.
  - `AccessTokenBridge` gives the axios interceptor `getAccessTokenSilently` in a layout effect, which runs before any child query fetches.
  - If Auth0 answers `login_required` (or a similar error), it calls `loginWithRedirect`.
- **Roles:**
  - Read with `jwt-decode` from the access token's `https://fitnessclub/roles` claim. The API's post-login Action already puts them there.
  - `useRoles` caches them in TanStack Query.
  - `RequireRole` guards route groups, and the navigation hides what a role can't open.
  - The API still enforces every rule.
- **Errors:**
  - A global `MutationCache.onError` shows a red notification.
  - Its title comes from the mutation's `meta.errorTitle`. Its text comes from `problemMessage`, which prefers the problem `detail`, then joins validation `errors`, then falls back to a sentence for the status.
  - Query errors show inline `Alert`s.
- **Cache refresh:** after a write, the mutation invalidates the generated query keys it affects. Session keys are invalidated by the `/api/sessions` prefix.

## Forms

- Each form schema `.extend()`s the generated request schema. It tightens fields where .NET's metadata is loose: `[StringLength]` emits `minLength: 0`, `[Required]` value types come out nullable, and `[Range]` fields come out optional. If the API adds a required field, the generated rule still applies and the form fails visibly.
- Schemas don't change types (no `transform`), because `react-hook-form-mantine` types `control` against the form values. A `toXRequest(values)` function maps form values to the generated request type. For example, it turns empty optional text into `null`.
- Submit handlers `await mutateAsync(...)`, and the Save button uses `formState.isSubmitting`, so a double click sends one request.
- Date fields use the browser's native date control (`TextInput type="date"`). Its value is a full real date or empty, never a half-typed one. Mantine's `DateInput` was dropped: when the typed text was not a real date it kept the previous value, so an impossible date silently saved the old date of birth, the slot date or today. An empty date never has a meaning of its own: the membership start date is required and prefilled with today. zod reports out-of-range dates.
- Times use `TimeInput` (`HH:mm`). The request adds `:00`.

## Screens and roles

| Screen | Path | Roles | Requirement |
|---|---|---|---|
| Check-in | `/check-in` | Admin, Receptionist | Visits |
| Clients | `/clients`, `/clients/:id` (header card plus `?tab=memberships\|visits\|messages`, see [[2026-10-09-client-contacts-and-page-design]]) | Admin, Receptionist | Clients, memberships, visits |
| Schedule | `/schedule` | Admin, Receptionist; Trainer sees "My schedule" (`/api/sessions/mine`), read-only | Group and individual sign-ups |
| Trainers | `/trainers`, `/trainers/:id` | Admin, Receptionist (read); Admin writes | Trainer profile, hours, clients |
| Rooms | `/rooms` | All roles (read); Admin writes | Rooms for sessions |
| Membership plans | `/plans` | Admin, Receptionist (read); Admin writes | Plans |
| Notifications | `/notifications` | Admin | Expiry notifications |
| Reports | `/reports?tab=activity\|revenue\|load` | Admin | Three reports |

`/` sends each role to its first allowed screen. A signed-in user without a club role sees "No access".

## Time

- Times are shown in the browser's time zone. The club's staff use the club's machines, so this equals the club time zone, which the API also assumes.
- Session `start`/`end` are sent as ISO strings with the local offset.

## Deployment

- `ui/Dockerfile`:
  - Builds with Node 24, using `VITE_AUTH0_*` build args. The build fails if they are missing.
  - Serves with `nginxinc/nginx-unprivileged` on port 8080.
- nginx:
  - Serves the SPA with a fallback to `index.html` and caches `/assets` forever.
  - Proxies `/api/` to `api:8080`.
- Compose publishes the UI on `8081`.

## Testing

- Each feature is tested at page level with Testing Library and MSW. Handlers come from the Orval-generated `*.msw.ts`, with fixed responses per test.
- `MantineProvider env="test"` turns off transitions and portals.
- jsdom gaps are stubbed in `src/test/setup.ts`:
  - `matchMedia` matches only the empty query, as browsers do, which mantine-datatable needs.
  - `ResizeObserver`, `scrollIntoView` and `elementFromPoint` are stubbed.
- Auth0 is replaced with a fake whose access token carries the test's roles.

## Open items

- `api/appsettings.Development.json` uses `https://dev-rtc-identity.eu.auth0.com/api/v2/` as its audience. That is the Auth0 Management API. The UI must request the same audience as the API, so create the API in Auth0 (for example `https://api.fitnessclub`) and point both sides to it.
- Currency is `UAH` (`src/lib/format.ts`).
- The main JS chunk is about 880 kB, 263 kB gzipped, mostly Mantine. Pages are lazy-loaded. The warning limit is raised to 1000 kB.
