# Система управління фітнес-клубом

## Опис

Потрібно створити інформаційну систему для автоматизації роботи фітнес-клубу.

## Основні функції системи

- Облік клієнтів (ПІБ, вік, телефон, абонемент, термін дії абонемента).
- Відстеження відвідувань: кожен прихід клієнта реєструється у базі даних.
- Управління тренерами: кожен тренер має профіль (спеціалізація, графік роботи, список клієнтів).
- Запис на групові тренування та індивідуальні заняття.
- Можливість створення різних тарифних планів (разові відвідування, абонемент на місяць, рік тощо).
- Автоматичне повідомлення клієнтів про закінчення терміну дії абонемента.

## Звіти

- Загальний список клієнтів із зазначенням активності відвідувань.
- Звіт про доходи клубу за місяць / рік.
- Завантаженість тренерів та залів у різні дні.
